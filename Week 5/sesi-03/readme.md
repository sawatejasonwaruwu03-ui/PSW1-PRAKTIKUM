Mengubah class cards jadi catalog,dimana berfungsi untuk:
display: grid mengubah container menjadi Grid.
gap: 1rem memberikan jarak antar-card.
grid-template-columns: 1fr 1fr membuat dua kolom dengan lebar yang sama.
Grid Overlay  biasanya berupa garis-garis yang menunjukkan pembagian kolom dan baris.
320px=1 kolom=Ruang tidak cukup untuk dua card
768px=2 kolom=Ruang container cukup untuk dua card.
1200px=2 kolom=karena di batasi max-width nya
Card Internal=menambahkan link detail kelima card,mempertahankan satu class .card untuk semua kegiatan.
