1.Navigasi Konsisten,Kode ini berfungsi untuk memudahkan pengunjung berpindah dari satu halaman ke halaman lain dalam website. Tag <nav> membungkus menu navigasi, sedangkan tag <a> membuat setiap tautan yang dapat diklik.
2.href="css/style.css" berarti browser mencari file CSS di dalam folder css.
src="assets/lokasi.jpg" berarti browser mencari gambar lokasi.jpg di dalam folder assets.
alt="Lokasi kegiatan" adalah teks alternatif jika gambar tidak dapat ditampilkan.
Audit Website:Berdasarkan hasil audit keseluruhan, website Komunitas Web Mahasiswa diperiksa untuk memastikan setiap halaman memiliki struktur HTML yang benar, tampilan yang konsisten, serta navigasi yang berfungsi dengan baik. Pengujian meliputi akses menggunakan keyboard, responsivitas pada ukuran layar 320 px, 768 px, dan 1200 px, zoom 200%, validasi HTML, serta pemeriksaan tautan pada setiap halaman. Kesalahan HTML yang ditemukan, seperti tag </section> yang berlebihan, telah diperbaiki. Dengan dilakukannya audit dan perbaikan, website diharapkan menjadi lebih rapi, responsif, mudah diakses, dan nyaman digunakan. Seluruh perubahan kemudian disimpan melalui Git sebagai bagian dari integrasi proyek.
